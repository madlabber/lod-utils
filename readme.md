    Converts an existing lab into an automation sandbox.

2. [ONTAP Select Deploy Lab](https://raw.githubusercontent.com/madlabber/lod-utils/refs/heads/main/LD01417-ontap-select.md')
    
    Converts an existing lab into an ONTAP Select Deploy lab

3. [Code Snippets](https://raw.githubusercontent.com/madlabber/lod-utils/refs/heads/main/snippets.md')
    
    Code snippets for for use in various labs
