# lod-utils

This is a collection of customizations and code snippets for use in NetApp Lab On Demand.


1. [Automation Sandbox Lab](https://github.com/madlabber/lod-utils/blob/main/LD01417-automation.md)

    Converts an existing lab into an automation sandbox.

2. [ONTAP Select Deploy Lab](https://github.com/madlabber/lod-utils/blob/main/LD01417-ontap-select.md)
    
    Converts an existing lab into an ONTAP Select Deploy lab.

3. [Code Snippets](https://github.com/madlabber/lod-utils/blob/main/snippets.md)
    
    Code snippets for for use in various labs.
